# So you want to contribute!

Hi! :D

I presume by now you've read the README and know what this project is about, so, here's some basic guidance as you write your contribution...

For V0.0.1, The included harness is incredibly basic, and intentionally so, this is meant to be iterated upon by anyone and everyone as a open learning opporitunity! Come build a harness from scratch with me!

# On AI...

## AI Generated Code

Will be declined, or removed if reliably proven to be AI written, I will try to be generous, avoiding flagrant vibe (read: unfair) checks, but sometimes judgement calls might be made. I will always open discussion around these though to weigh opinions from several people rather than just myself.

The entire point of this repo is as a opportunity for humans to tinker with and learn from live code that I dare hope someone will unironically use someday, letting an agent do that for you defeats the purpose of that.

## AI Generated Suggestions/Issues

Will be kept, and considered, I offer no promises on if I will follow up on them or not, however.

Issue spam will get you wholly ignored. Please, don't flood the issues, this is maintained and curated by one person.

## AI Assistance in general

Is fine, so long as you declare it in code such as...

```py
# I asked the AI of my choice about X concept, and learned how to properly implement it, as seen below ~ Wulf715
_ = 1 # Your code goes here.
```

What matters is, that you, as a person, wrote the code, how you learned how to write it is of no concern to me and in fact I encourage you, if you are struggling, to learn however you can, even though the assistance of an AI.

## In short:

AI generated code will be outright declined.

AI suggestions will be kept, and considered, with no promises given.

AI assistance (e.g. for the learning of a given concept) should be declared.
